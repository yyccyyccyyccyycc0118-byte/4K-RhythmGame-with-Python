# 🎵 MyRhythmGame

![Python Version](https://img.shields.io/badge/Python-3.x-blue.svg)
![Pygame](https://img.shields.io/badge/Pygame-Powered-green.svg)

**MyRhythmGame** 是一款基于 Python 与 Pygame 开发的轻量级 4K 下落式音乐游戏。
项目不仅包含了核心的**音游游玩端**，还内置了**全功能可视化谱面编辑器**以及**osu! 谱面转换器**。

本项目的核心亮点在于：**极致轻量的底层架构**。我们完全摒弃了 Numpy、FFmpeg、SciPy 等庞大的第三方模块，通过 CTypes 原生绑定了 C 语言级别的殿堂级变调算法 `sonic`，实现了**「秒级变倍速且不变调」**及完美的音符精度，带来真正畅快硬核的音游体验！

---

## ✨ 核心特性 / Features

- **原生极致优化**：抛弃繁重的 Python 数学库，游戏内部集成编译 C 语言 `sonic` 动态库处理音频，毫秒级内存响应，打包后体积微小。
- **自定义变速变调**：支持 0.5x ~ 2.0x 游戏内歌曲倍速（不变调），配合极速 C 层算法“即点即玩”。
- **全功能制谱器**：内置 `editor.py` 提供所见即所得的制谱环境，支持鼠标拖拽长条、自动工程打包、一键局部/全局删谱、BPM与节拍吸附。
- **多平台自适应**：不论 Linux 还是 Windows 均可顺畅运行，缺失运行库时可自动调用 GCC 静默极速编译（针对开发者环境）。
- **osu! 谱面无缝导入**：通过内置转换器，可快速将其他来源的 4K osu!mania 经典谱面移入本机游玩。

## 🚀 快速开始 / Getting Started

### 1. 环境要求
你只需要拥有 Python 以及最基础的 Pygame 媒体库：
```bash
pip install pygame
```
> *注：首次更改倍速时，程序会检测同目录是否存在 `libsonic.so` / `sonic.dll`。若无，会自动尝试利用系统中的 `gcc` 进行一次性毫秒级静态编译。*

### 2. 启动游戏
项目拆分为了三个入口，各司其职：
- **运行主游戏**: `python main.py`
- **运行编辑器**: `python editor.py`
- **转换 osu 谱面**: `python osu_converter.py`

## 🎮 游玩指南 / How to Play

在主菜单（Main Menu）中，除了选择歌曲，你还可以实时调节各种硬核音游参数以挑战自我极限！

### 主界面快捷键：
| 按键 | 功能说明 |
| :--- | :--- |
| `↑` / `↓` | 切换选中的常规曲目 |
| `Enter` | 开始游玩 |
| `<` / `>` | 改变音符下落流速 (**Speed**) - *结合 `Shift` 微调步长 0.01* |
| `A` / `D` | 游戏全局音频/铺面同步偏移 (**Offset**) - *结合 `Shift` 微调步长 1ms* |
| `W` / `E` | 设置歌曲游玩倍速 (**Rate**，变速不变调) - *结合 `Shift` 微调步长 0.01x* |
| `F` | 切换全屏模式 |
| `R` | 循环切换窗口分辨率比例 |
| `S` | 进入系统详细设置界面 |

### 局内游玩：
- **按键操作**：默认采用标准的 4K 手元键位布局（支持在设置中自行映射）。
- **判定机制**：精准判定基于底边像素，毫秒级帧刷新，长按条（Hold）底边锁死无视觉抖动。

## 🎹 制谱器说明 / Editor Guide

启动 `editor.py` 即可进入“所见即所得”的制谱模式。这是专为创作者准备的强大兵器库！

### 鼠标操作
- **放置单键 (Tap)**: `鼠标左键`单击轨道任意位置。
- **放置长条 (Hold)**: `鼠标左键`在轨道上按住并上下拖拽至理想长度后松开。
- **删除音符**: `鼠标右键`瞄准已有音符即可抹除。

### 键盘快捷键 (随时按 `O` 键呼出面板)
| 按键 | 核心功能 |
| :--- | :--- |
| `Space` | 播放 / 暂停对照谱面 |
| `Up/Down` | 画面时间轴上下滚动 |
| `-` / `=` | 缩放轨道视野（调整下落速度参考） |
| `Q` / `E` | 减少 / 增加 节拍线吸附精度 (Divisor) |
| `G` | 开启 / 关闭 强制网格吸附 |
| `[ / ]` | 增减 1.0 BPM（结合 `Shift` 微调 0.1 BPM） |
| `W / R` | 调节编辑器内音频对照的播放速度倍率 |
| `Left/Right` | 调整当前谱面的额外偏移量 (-5/+5 ms) |
| `I` | 选取并导入全新的 `.mp3`/`.wav` 音频文件 |
| `C` | 选取并导入背景/曲绘 `.jpg`/`.png` 封面图片 |
| `L` | 加载已存在的 `map.json` 覆盖当前工程 |
| `S` | **一键保存工程** (自动在 `songs/` 下创建文件夹归档并转移素材) |
| **`Del`** | **一键删除当前屏幕（可见范围内）的所有音符** |
| **`Ctrl` + `Del`** | **毁灭级清空整首歌曲内的所有音符数据** |
| `O` | 开启/关闭这份帮助菜单的视觉遮罩 |

## 📂 谱面导入与目录结构

所有谱面资源都放置在游戏根目录下的 `songs/` 文件夹中。

一个标准的歌曲工程包含以下内容：
```text
songs/
  ├── My Awesome Song/
  │    ├── audio.mp3    # 歌曲文件
  │    ├── bg.jpg       # 背景贴图 / UI 封面
  │    └── map.json     # 核心谱面文件，由 Editor 或 Converter 生成
  └── Another Song/
```

**快速导入 Osu! 谱面：**
只需解压 Osu 的 `.osz` 文件，运行 `python osu_converter.py` ，按照终端提示输入来源路径，程序即可自动解析 `.osu` 并输出为你能在本机完美游玩的格式。

## 📦 游戏打包 (构建 EXE)

若想发给小伙伴游玩，本游戏支持通过 **PyInstaller** 达成「三端合一且共用环境」的高效静态发发：

```bash
# 1. 建立虚拟纯净环境并安装核心库
python -m venv venv
venv\Scripts\activate
pip install pygame pyinstaller

# 2. 生成底层必备动态库 (执行一次编辑器或随意脚本即可)
python sonic_python.py

# 3. 使用预设合集脚本自动完成收集、去重、分发
pyinstaller build_all.spec --clean
```
最终即可在 `dist/MyRhythmGame_Bundle` 内获得随时可拷走运行、开箱即用的三大客户端绿色珍藏版（不含各种多余的库污染，超级纯净）。
